# RocketMQ 消息生产者拦截器系统架构

## 系统概述

本系统实现了一个完整的RocketMQ消息生产者拦截器体系，采用责任链模式设计，支持消息的验证、加密、标签过滤、统计监控等功能。

## 架构设计

### 1. 整体架构图

```
┌─────────────────────────────────────────────────────────────┐
│                    RocketMQ Producer                        │
└─────────────────────┬───────────────────────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────────────────────┐
│                MessageProducerComponent                     │

                      │
                      ▼

└─────────────────────┬───────────────────────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────────────────────┐
│                    拦截器执行链                             │
│  ┌─────────────┬─────────────┬─────────────┬─────────────┐  │
│  │  验证拦截器  │  加密拦截器  │ 标签过滤拦截器│  统计拦截器  │  │
│  │   (100)    │   (150)    │   (200)    │   (300)    │  │

└─────────────────────────────────────────────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────────────────────┐
│                    RocketMQ Broker                         │
└─────────────────────────────────────────────────────────────┘
```

### 2. 拦截器执行流程

#### 消息发送前 (beforeSend)
```
消息创建 → 验证拦截器 → 加密拦截器 → 标签过滤拦截器 → 统计拦截器 → 发送消息
```

#### 消息发送后 (afterSend)
```
发送结果 → 统计拦截器 → 标签过滤拦截器 → 加密拦截器 → 验证拦截器 → 完成
```

#### 异常处理 (onException)
```
异常发生 → 统计拦截器 → 标签过滤拦截器 → 加密拦截器 → 验证拦截器 → 异常记录
```

## 核心组件

### 1. MessageInterceptor 接口

```java
public interface MessageInterceptor {
    Message beforeSend(Message message);
    void afterSend(Message message, SendResult sendResult);
    void onException(Message message, Throwable throwable);
    int getOrder(); // 优先级控制
}
```

**设计原则**:
- 单一职责：每个拦截器只负责一个特定功能
- 开闭原则：支持扩展新的拦截器类型
- 依赖倒置：依赖抽象接口而非具体实现

### 2. MessageInterceptorChain 拦截器链管理器

**核心功能**:
- 自动扫描和注册拦截器
- 按优先级排序执行
- 异常隔离处理
- 提供拦截器管理接口

**关键特性**:
- 使用Spring的依赖注入自动发现拦截器
- 支持动态拦截器管理
- 提供拦截器状态查询

### 3. 具体拦截器实现

#### MessageValidationInterceptor (优先级: 100)
- **职责**: 消息格式和内容验证
- **功能**: 大小检查、格式验证、敏感词检测
- **配置**: 支持自定义大小限制和验证规则

#### MessageEncryptionInterceptor (优先级: 150)
- **职责**: 敏感消息加密处理
- **功能**: AES加密、自动识别敏感内容
- **配置**: 支持密钥配置和加密开关

#### MessageTagFilterInterceptor (优先级: 200)
- **职责**: 消息标签自动生成和分类
- **功能**: 智能标签生成、消息分类、来源标识
- **配置**: 支持自定义标签映射规则

#### MessageStatisticsInterceptor (优先级: 300)
- **职责**: 消息发送统计和监控
- **功能**: 数量统计、性能监控、分类统计
- **配置**: 支持统计间隔和保留时间配置
